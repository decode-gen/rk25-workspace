Module 5 · Java Web & Enterprise Framework (Spring Boot)

Học phần phát triển ứng dụng cấp doanh nghiệp quy mô lớn (Enterprise Grade), thiết kế kiến trúc RESTful Microservices, tích hợp CSDL quan hệ với Spring Data JPA và bảo mật với Spring Security.

Kế hoạch đào tạo Học phần tốt nghiệp theo lộ trình đào tạo

Hệ thống đề tài đồ án tốt nghiệp, bài tập thực hành kiến trúc doanh nghiệp và tài liệu chuyên sâu của Module 5 sẽ được mở theo tiến độ giảng dạy trên lớp của giảng viên phụ trách. Học viên hiện đang tập trung hoàn thành các bài tập thực hành và đồ án của Module 2: Cơ sở dữ liệu & SQL.
