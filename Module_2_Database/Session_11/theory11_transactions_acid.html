Lý thuyết Giao dịch Transaction & Hệ Tiêu Chuẩn ACID

Làm chủ kỹ thuật quản lý giao dịch an toàn: START TRANSACTION, COMMIT, ROLLBACK, xử lý All-or-Nothing và cơ chế tự động Rollback qua DECLARE EXIT HANDLER.

1. Hệ Tiêu Chuẩn ACID trong Cơ Sở Dữ Liệu

Một hệ thống tài chính ngân hàng hoặc bán hàng trực tuyến không thể thiếu Transaction để ngăn chặn lỗi "tiền bị trừ ở tài khoản A nhưng tài khoản B chưa nhận được".

A - Atomicity (Nguyên tử):

Tất cả câu lệnh cùng thành công hoặc cùng thất bại hoàn toàn. Không bao giờ tồn tại trạng thái dở dang.

START TRANSACTION;
UPDATE accounts SET balance = balance - 500 WHERE id = 1;
UPDATE accounts SET balance = balance + 500 WHERE id = 2;
COMMIT;
C - Consistency (Nhất quán):

Tổng giá trị và các ràng buộc dữ liệu trước và sau giao dịch luôn được bảo đảm chính xác.

-- Nếu phát hiện số dư âm:
IF balance < 0 THEN
    ROLLBACK;
END IF;
I - Isolation (Độc lập):

Nhiều giao dịch diễn ra đồng thời không làm sai lệch kết quả của nhau.

D - Durability (Bền vững):

Dữ liệu sau khi COMMIT được ghi an toàn xuống ổ cứng, chống sập nguồn.

2. Xử lý Ngoại lệ tự động với DECLARE EXIT HANDLER

Khi nhúng Transaction vào Stored Procedure, ta sử dụng EXIT HANDLER FOR SQLEXCEPTION để tự động hoàn tác khi xảy ra bất kỳ lỗi hệ thống nào:

DELIMITER //
CREATE PROCEDURE sp_safe_transfer(IN p_from INT, IN p_to INT, IN p_val DECIMAL(12,2))
BEGIN
    DECLARE EXIT HANDLER FOR SQLEXCEPTION
    BEGIN
        ROLLBACK;
        SELECT 'Lỗi SQL! Toàn bộ giao dịch đã được ROLLBACK an toàn.' AS err;
    END;

    START TRANSACTION;
    UPDATE accounts SET balance = balance - p_val WHERE id = p_from;
    UPDATE accounts SET balance = balance + p_val WHERE id = p_to;
    COMMIT;
END //
DELIMITER ;
