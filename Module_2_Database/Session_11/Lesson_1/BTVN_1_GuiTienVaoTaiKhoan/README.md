# BTVN 1: Gửi tiền vào tài khoản (Session 11)

## 1. Mục tiêu
- Hiểu cách sử dụng START TRANSACTION và COMMIT
- Thực hiện cập nhật dữ liệu an toàn trong MySQL

## 2. Mô tả & Yêu cầu
- Bảng accounts lưu thông tin: account_id, customer_name, balance (10 tài khoản mẫu)
- Bắt đầu transaction
- Cộng thêm 1.000.000 VNĐ vào tài khoản có account_id = 1
- Lưu thay đổi bằng COMMIT
- Kiểm tra số dư trước và sau giao dịch
