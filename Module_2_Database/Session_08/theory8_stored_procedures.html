Lý thuyết Stored Procedures trong MySQL

Tìm hiểu toàn diện về Stored Procedure: nguyên lý hoạt động, cú pháp DELIMITER, tham số IN / OUT, khai báo biến DECLARE và cấu trúc rẽ nhánh điều khiển IF/CASE.

1. Khái niệm & Cú pháp Stored Procedure

Stored Procedure (Thủ tục lưu trữ) là một đoạn chương trình gồm nhiều câu lệnh SQL được biên dịch và lưu trữ vĩnh viễn trên Database Server. Ứng dụng gọi thủ tục thông qua lệnh CALL.

Cú pháp tạo Stored Procedure (MySQL): 
DELIMITER //
CREATE PROCEDURE sp_example(
    IN p_id INT,
    OUT p_name VARCHAR(100)
)
BEGIN
    SELECT full_name INTO p_name 
    FROM employees 
    WHERE id = p_id;
END //
DELIMITER ;
Gọi và thực thi Stored Procedure: 
-- Gọi thủ tục có tham số OUT:
CALL sp_example(1, @emp_name);

-- Xem kết quả trả ra biến session:
SELECT @emp_name AS employee_name;

-- Xóa thủ tục:
DROP PROCEDURE IF EXISTS sp_example;

Lợi ích cốt lõi của Stored Procedure:

  • Tăng hiệu năng: SQL Server tối ưu hóa và lưu sẵn kế hoạch thực thi trong bộ nhớ đệm (Plan Cache), không mất thời gian parse lại câu lệnh.
  • Tiết kiệm băng thông: Client chỉ gửi tên procedure và đối số qua mạng thay vì gửi câu lệnh SQL đồ sộ.
  • Bảo mật & Ngăn chặn SQL Injection: Ẩn hoàn toàn cấu trúc bảng vật lý phía sau thủ tục và ép kiểu chặt chẽ cho tham số.

2. Tham số (IN, OUT, INOUT) & Cấu trúc điều khiển (IF, CASE)

Khai báo biến & IF - ELSE: 
DELIMITER //
CREATE PROCEDURE sp_eval_salary(IN p_salary DECIMAL(10,2))
BEGIN
    DECLARE v_result VARCHAR(30);
    IF p_salary >= 15000000 THEN
        SET v_result = 'Thu nhập cao';
    ELSE
        SET v_result = 'Thu nhập cơ bản';
    END IF;
    SELECT v_result AS danh_gia;
END //
DELIMITER ;
Cấu trúc rẽ nhánh CASE - WHEN: 
CASE 
    WHEN score >= 8.0 THEN SET rank = 'Giỏi';
    WHEN score >= 6.5 THEN SET rank = 'Khá';
    WHEN score >= 5.0 THEN SET rank = 'Trung bình';
    ELSE SET rank = 'Yếu';
END CASE;
