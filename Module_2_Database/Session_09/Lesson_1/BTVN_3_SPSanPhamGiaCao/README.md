# BTVN 3: Thủ tục lấy sản phẩm giá cao (Session 09)

## 1. Mục tiêu
- Làm quen Stored Procedure lọc dữ liệu kết hợp điều kiện CHECK
- Đóng gói truy vấn thường xuyên trên sản phẩm cao cấp

## 2. Mô tả & Yêu cầu
- Bảng products: product_id, product_name, price, stock (thêm 20 bản ghi)
- Tạo Stored Procedure get_high_value_products
- Lấy về danh sách tất cả các sản phẩm có giá lớn hơn 1.000.000 VNĐ
- Sắp xếp giảm dần theo giá bán
