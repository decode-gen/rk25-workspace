# BTVN 1: Làm quen với View (Một bảng)

## 1. Mục tiêu
- Hiểu khái niệm VIEW là bảng ảo không lưu dữ liệu vật lý
- Tạo VIEW từ một bảng để bảo mật và chọn lọc dữ liệu hiển thị

## 2. Mô tả & Yêu cầu
- Bảng students: student_id, full_name, birth_year, class_name, address
- Giảng viên chỉ cần xem thông tin cơ bản
- Tạo VIEW _student_basic chỉ gồm student_id, full_name, class_name
