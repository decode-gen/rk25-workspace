# Session 06: Luyện tập truy vấn tổng hợp CSDL

## 1. Mục tiêu kiến thức
- Rèn luyện kỹ năng kết hợp các kỹ thuật truy vấn DML & DQL: SELECT, WHERE, ORDER BY, GROUP BY, HAVING, LIMIT.
- Thành thạo các phép nối bảng: INNER JOIN, LEFT JOIN, RIGHT JOIN.
- Nắm vững kỹ thuật viết truy vấn con lồng nhau (Subquery) trên nhiều mức logic.
- Phân tích và giải quyết các bài toán dữ liệu thực tế: Doanh thu, Khách hàng VIP, Tồn kho và Thống kê mặt hàng.

## 2. Danh sách bài tập (BTVN)
1. **BTVN 1:** Quản lý sản phẩm & danh mục
2. **BTVN 2:** Quản lý Khách hàng & Đơn hàng
3. **BTVN 3:** Tìm kiếm sản phẩm nâng cao
4. **BTVN 4:** Thống kê Doanh thu
5. **BTVN 5:** Truy vấn tổng hợp cho hệ thống bán hàng
