# BTVN 3: Tìm kiếm sản phẩm nâng cao

## 1. Mục tiêu
- Luyện tập BETWEEN, LIKE, GROUP BY, AVG, MIN, Subquery
- Phân tích sản phẩm theo danh mục và so sánh với mức trung bình chung

## 2. Yêu cầu & CSDL
- Tìm sản phẩm theo khoảng giá BETWEEN
- Tìm sản phẩm theo từ khóa tên LIKE '%Pro%'
- Tính giá trung bình từng danh mục
- Tìm sản phẩm có giá cao hơn giá trung bình toàn bộ hệ thống
- Tìm sản phẩm giá rẻ nhất theo từng danh mục
