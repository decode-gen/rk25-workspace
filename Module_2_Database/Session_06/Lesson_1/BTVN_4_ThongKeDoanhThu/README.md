# BTVN 4: Thống kê Doanh thu

## 1. Mục tiêu
- Tính toán doanh thu thương mại điện tử
- Ứng dụng SUM, AVG, GROUP BY, ORDER BY, LIMIT
- Tìm kiếm đơn hàng lớn nhất và top sản phẩm bán chạy

## 2. Yêu cầu & CSDL
- Thêm đơn hàng mới và chi tiết tương ứng
- Tính tổng doanh thu toàn cửa hàng và doanh thu trung bình mỗi đơn hàng
- Hiển thị đơn hàng có doanh thu cao nhất (LIMIT 1)
- Hiển thị Top 3 sản phẩm bán chạy nhất dựa trên tổng số lượng bán
